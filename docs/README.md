# Geometric Lib

## 1. Общее описание решения

Библиотека Geometric Lib содержит функции для вычисления
площади и периметра геометрических фигур: круга, квадрата,
прямоугольника и треугольника.

Каждая функция реализована в отдельном файле.

### Math formulas

#### Area

- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²
- Triangle: S = ah/2

#### Perimeter

- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
- Triangle: P = a + b + c

## 2. Описание функций с примерами вызова

### circle.py

#### area(r):

    Принимает радиус круга, возвращает площадь круга
    Пример вызова: area(5), вернёт 78.53981633974483

#### perimeter(r):

    Принимает радиус круга, возвращает длину окружности
    Пример вызова: perimeter(5), вернёт 31.41592653589793

### square.py

#### area(a):

    Принимает сторону квадрата, возвращает площадь этого квадрата
    Пример вызова: area(5), вернёт 25

#### perimeter(a):

    Принимает сторону квадрата, возвращает периметр этого квадрата
    Пример вызова: perimeter(5), вернёт 20

### rectangle.py

#### area(a, b):

    Принимает стороны прямоугольника, возвращает площадь этого прямоугольника
    Пример вызова: area(3, 5), вернёт 15

#### perimeter(a, b):

    Принимает стороны прямоугольника, возвращает периметр этого прямоугольника
    Пример вызова: perimeter(3, 5), вернёт 16

### triangle.py

#### area(a, h):

    Принимает сторону треугольника a и высоту опущенную на эту сторону, возвращает площадь треугольника
    Пример вызова: area(3, 6), вернёт 9

#### perimeter(a, b, c):

    Принимает стороны треугольника, возвращает его периметр
    Пример вызова: perimeter(3, 5, 6), вернёт 14
