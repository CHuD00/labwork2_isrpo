# Geometric Lib

## 1. Общее описание решения

Библиотека Geometric Lib содержит функции для вычисления
площади и периметра геометрических фигур: круга, квадрата,
прямоугольника и треугольника.

Каждая функция реализована в отдельном файле.

### Math formulas

#### Area

- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²
- Triangle: S = ah/2

#### Perimeter

- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
- Triangle: P = a + b + c

## 2. Описание функций с примерами вызова

### circle.py

#### area(r):

    Возвращает площадь круга
    Принимает:
    - r-радиус круга
    Возвращаемое значение:
        πR²(float)
    Пример вызова: area(5), вернёт 78.53981633974483

#### perimeter(r):

    Возвращает длину окружности
    Принимает параметры:
    - r-радиус круга
    Возвращаемое значение:
        2πR(float)
    Пример вызова: perimeter(5), вернёт 31.41592653589793

### square.py

#### area(a):

    Возвращает площадь квадрата
    Принимает параметры:
    - a-сторону квадрата
    Возвращаемое значение:
        a²(float)
    Пример вызова: area(5), вернёт 25

#### perimeter(a):

    Возвращает периметр квадрата
    Принимает параметры:
    - a-сторону квадрата
    Возвращаемое значение:
        4*a(float)
    Пример вызова: perimeter(5), вернёт 20

### rectangle.py

#### area(a, b):

    Возвращает площадь прямоугольника
    Принимает параметры:
    - a-длина прямоугольника
    - b-ширина прямоугольника
    Возвращаемое значение:
        a*b(float)
    Пример вызова: area(3, 5), вернёт 15

#### perimeter(a, b):

    Возвращает периметр прямоугольника
    Принимает параметры:
    - a-длина прямоугольника
    - b-ширина прямоугольника
    Возвращаемое значение:
        2*a + 2*b(float)
    Пример вызова: perimeter(3, 5), вернёт 16

### triangle.py

#### area(a, h):

    Возвращает площадь треугольника
    Принимает параметры:
    - a-сторона треугольника
    - h-высота опущенная на эту сторону
    Возвращаемое значение:
        a*h/2(float)
    Пример вызова: area(3, 6), вернёт 9

#### perimeter(a, b, c):

    Возвращает периметр треугольника
    Принимает параметры:
    - a-первая сторона трегольника
    - b-вторая сторона трегольника
    - c-третья сторона трегольника
    Возвращаемое значение:
        a+b+c(float)
    Пример вызова: perimeter(3, 5, 6), вернёт 14
